# Third-party UI references and adapted components

YSuite's product UI layer uses interaction structures and, where noted in source headers, adapted UI code from permissively licensed open-source projects.

## Android Now in Android

Repository: android/nowinandroid  
License: Apache License 2.0  
Use: adaptive navigation and dashboard/application layout conventions.

## FileExplorer

Repository: SysAdminDoc/FileExplorer  
License: MIT  
Copyright (c) 2025 SysAdminDoc  
Use: file-manager workspace conventions plus provider/repository capability architecture for local, SAF, Root, Shizuku, archive, network and cloud storage.
